\# ⚡ Quick Start - 5 Minutes



\## TL;DR - Get it running now!



\### Step 1: Get API Key (1 min)

1\. Go to https://console.anthropic.com

2\. Click "API Keys" → "Create Key"

3\. Copy the key (`sk-ant-...`)



\### Step 2: Install \& Run Backend (2 min)

```bash

pip install -r requirements.txt

python backend.py

```



You should see:

```

&nbsp;\* Running on http://0.0.0.0:5000

```



\### Step 3: Open Frontend (2 min)

\- Double-click `index.html` OR

\- Run: `python -m http.server 8000`

\- Visit: http://localhost:8000



\### Step 4: Connect \& Create (0 min - watch magic happen!)

1\. Paste API key in frontend

2\. Click "Connect \& Validate"

3\. Describe a website you want:

&nbsp;  ```

&nbsp;  A dark portfolio website for a freelance designer with:

&nbsp;  - Beautiful hero section

&nbsp;  - Project showcase

&nbsp;  - Contact form

&nbsp;  - Modern responsive design

&nbsp;  ```

4\. Click "🚀 Let Team Create Website"

5\. \*\*Wait 30-60 seconds\*\* and watch the AI team build it!

\## Common Issues?



\*\*"Can't connect to backend"\*\*

\- Is Flask running? Check terminal for: `Running on http://0.0.0.0:5000`

\- Try Backend URL: `http://localhost:5000`



\*\*"Invalid API key"\*\*

\- Did you copy the whole key? Should start with `sk-ant-`

\- Get a new one at https://console.anthropic.com



\*\*"It's taking forever"\*\*

\- AI is thinking! Wait 30-60 seconds

\- Longer prompts = longer wait
